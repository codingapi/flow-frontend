# @coding-flow/flow-mobile-ui

Flow Engine 移动端基础 UI 组件库，提供原子化 UI 组件。

## 简介

`flow-mobile-ui` 是 Flow Engine 移动端的基础 UI 组件库，提供原子化的移动 UI 组件：

- 基础输入组件（按钮、输入框、选择器等）
- 数据展示组件（列表、卡片等）
- 反馈组件（弹窗、消息提示、加载等）
- 布局组件（容器等）

基于 Ant Design Mobile 组件库构建，提供统一的设计风格。

### 依赖关系

- **依赖**: `@coding-flow/flow-core`、`antd-mobile`

## Setup

安装依赖:

```bash
pnpm install
```

## 开发

构建组件库:

```bash
pnpm run build
```
