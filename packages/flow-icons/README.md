# @coding-flow/flow-icons

Flow Engine 图标库，提供流程设计器与审批场景所需的图标。

## 简介

`flow-icons` 是 Flow Engine 的图标库，提供：

- 流程节点图标（审批、办理、通知、路由、并行等）
- 审批动作图标（通过、拒绝、加签、委派、退回、转办等）
- 设计器工具图标

基于 `@ant-design/icons` 构建。

### 依赖关系

- **依赖**: `@coding-flow/flow-core`、`@ant-design/icons`

## Setup

安装依赖:

```bash
pnpm install
```

## 开发

构建组件库:

```bash
pnpm run build
```
